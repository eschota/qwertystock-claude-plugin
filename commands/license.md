The user wants a full-resolution Qwertystock file: $ARGUMENTS

Follow the `stock-media-licensing` skill:

1. Look the item up with the `get_item` tool. Accept an item page link such as `https://qwertystock.com/item?id=3011233` and use its `id`.
2. Recommend a format that fits how the user will use the file, and state its price in USD.
3. Check the planned use against the licence summary, and say so when it needs more than the standard licence.
4. Give the item page link, where the user buys the file themselves.
