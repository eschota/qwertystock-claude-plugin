# Changelog

## 1.0.0

- First release: a dependency-free, read-only local MCP server with the `search_media` and `get_item` tools.
- `stock-media-search` and `stock-media-licensing` skills, and the `find` and `license` commands.
- Search attaches thumbnails so Claude can check the results, and fills in prices that the search results leave out.
- The plugin never buys anything: users buy files themselves on the item page at qwertystock.com.
